iPhone: set it up once

  1. Open the Shortcuts app and tap +.
  2. Add Ask for Input. Set the question to "What's the task?"
  3. Add Get Contents of URL. Paste this address:
  1. Tap Show More. Method: POST.
  2. Headers: add Authorization with the value Bearer, a space, then your key.
  3. Request Body: JSON. Add a text field named text and pick Provided Input.
  4. Add Get Dictionary Value for the key message, then Speak Text.
  5. Name the shortcut Add to Quantum. Now say "Hey Siri, add to Quantum".

Android

  • Share to Quantum: in any app, tap Share and pick Quantum Manager. It opens as a new task. (Install the app first.)
  • Long-press the app icon for New task, Alarms and New note.
  • By voice: apps like HTTP Shortcuts or Tasker can send text to the same address with the same key, and you can start them with "Hey Google".
